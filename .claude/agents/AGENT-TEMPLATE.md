## 工作流程

1. **理解任务**：明确目标和范围
2. **收集信息**：读取相关文件和代码
3. **分析处理**：执行核心职责
4. **输出结果**：按标准格式返回

## 输出控制（必须遵守）

1. **严格遵守长度要求**：如调用者说"不超过10行"则必须≤10行
2. **返回摘要**：被 Task 调用时只返回关键结论
3. **不给主观评分**：不说"95分"、"建议上线"等
4. **不确定标记**：不确定的问题标记"待确认"，不要猜测
5. **先读后说**：不凭印象判断，先读取相关文件

## 项目上下文

### WizPulseAI 三站点架构

```
wizPulseAI/
├── wizPulseAI-com/          # Main站点
├── auth-wizpulseai-com/     # Auth站点
├── db-wizPulseAI-com/       # Dashboard站点
└── fashion-wizpulseai-com/  # Fashion产品站
```

### 技术栈

- **前端**：Next.js 14, React, Tailwind CSS
- **后端**：Supabase (Auth + Database + Storage)
- **支付**：Stripe
- **部署**：Vercel
