# SEO/AEO/GEO 检查清单

> 审计和优化时使用

---

## SEO 检查清单

### 关键词
- [ ] 关键词研究完成（日/英分开）
- [ ] 用户意图分类（信息/交易/导航）
- [ ] 长尾关键词列表
- [ ] 问题型关键词列表

### On-page 优化
- [ ] H1 每页一个，含主关键词
- [ ] H2/H3 问题式标题
- [ ] 内部链接建立（3-5个/页）
- [ ] 外部链接引用权威来源
- [ ] 图片 alt 属性添加
- [ ] 图片压缩优化

### 技术 SEO
- [ ] robots.txt 配置正确
- [ ] sitemap.xml 生成并提交
- [ ] HTTPS 全站启用
- [ ] 移动端友好
- [ ] URL 友好结构
- [ ] 面包屑导航

### 性能（Core Web Vitals）
- [ ] LCP < 2.5s
- [ ] FID < 100ms
- [ ] CLS < 0.1

### 结构化数据
- [ ] Organization Schema
- [ ] WebSite Schema
- [ ] Article Schema
- [ ] SoftwareApplication Schema
