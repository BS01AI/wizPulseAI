## 文案结构

### Landing Page 标准结构

```
┌─────────────────────────────────┐
│  Hero区域                        │
│  ・主标语（价值观/身份）          │
│  ・副标语（具体利益）            │
│  ・CTA按钮                       │
└─────────────────────────────────┘
          ↓
┌─────────────────────────────────┐
│  价值主张区域                    │
│  ・3个核心价值点                 │
│  ・每个用一句话+一个图标         │
└─────────────────────────────────┘
          ↓
┌─────────────────────────────────┐
│  场景/使用案例                   │
│  ・具体场景（通学/デート等）      │
│  ・用户能得到的结果              │
└─────────────────────────────────┘
          ↓
┌─────────────────────────────────┐
│  社会证明                        │
│  ・用户评价                      │
│  ・使用数据                      │
└─────────────────────────────────┘
          ↓
┌─────────────────────────────────┐
│  最终CTA                         │
│  ・重复主标语                    │
│  ・CTA按钮                       │
└─────────────────────────────────┘
```

## 主标语（Hero Headline）

### 写法公式

| 公式 | 示例 |
|------|------|
| 不是X，是Y | 服を選ぶんじゃない。今日の自分を選ぶ。 |
| X比Y更重要 | 似合うより、「私っぽい」。 |
| X是可以Y的 | 自信は、着られる。 |
| 把X变成Y | 迷いを"自信"に変える。 |

### 检验标准

写完后问自己：

- [ ] 有没有提到产品功能？→ 有就删
- [ ] 能让用户想象自己变成谁？→ 不能就重写
- [ ] 读出来有没有感觉？→ 没有就重写
- [ ] 能用在Nike广告里吗？→ 不能就重写

## 副标语（Subheadline）

### 角色

补充主标语，给出具体利益或场景。

### 写法

| 主标语诉求 | 副标语方向 |
|-----------|-----------|
| 身份（成为谁） | 具体利益（得到什么） |
| 抽象价值观 | 具体场景 |
| 情感 | 行动 |

### 示例

| 主标语 | 副标语 |
|--------|--------|
| 似合うより、「私っぽい」。 | AIはコーデを作るんじゃない。"あなた"を引き出す。 |
| 迷う時間を、あなたの時間に。 | 通学・通勤・デート・推し活。場面に合わせて"即決"。 |
| 自信は、着られる。 | 出かける前の「どうしよう」を「よし、行こ」に。 |

## CTA（Call to Action）

### 原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 动词开头 | 行动感 | 選ぶ、始める、見る |
| 第一人称 | 用户视角 | 私のコーデを見る |
| 低门槛 | 减少心理障碍 | 無料で始める |
| 即时性 | 现在就做 | 今日のコーデを選ぶ |

### CTA 库

| 类型 | CTA |
|------|-----|
| 主动型 | 今日のコーデを選ぶ |
| 探索型 | 私のスタイルを見つける |
| 利益型 | 無料で始める |
| 紧迫型 | 今すぐ始める |
| 场景型 | シーンで選ぶ |

## 短句（SNS/バナー用）

### 特点

- 10字以内（日语）
- 一个核心信息
- 情感触发
- 可独立使用

### 短句库

| 类型 | 短句 |
|------|------|
| 时间 | 1分で、今日の"私"。 |
| 问题解决 | コーデ迷子、卒業。 |
| 共鸣 | "なんか違う"をなくす。 |
| 情感 | 気分が上がると、毎日が変わる。 |
| 身份 | ちゃんと可愛い、ちゃんと私。 |

---

## 价值主张（3个核心点）

### 结构

每个价值点 = 标题（5字）+ 说明（20字）

### 示例

| 标题 | 说明 |
|------|------|
| 迷わない朝 | 場面を選ぶだけ。1分で今日の私が決まる。 |
| 私らしい選択 | 似合うじゃなく、"私っぽい"を提案。 |
| クローゼット活用 | 手持ちの服で、新しい組み合わせを発見。 |

## 语气指南（日语）

### マジコーデ 语气

| 要素 | 选择 |
|------|------|
| 敬語レベル | です/ます（親しみ） |
| 文末 | 。で終わる（押しつけない） |
| 主語 | あなた/私（寄り添い） |
| トーン | 優しい、背中を押す |

### NG 语气

| NG | 理由 | OK |
|-----|------|-----|
| 絶対に〇〇！ | 押しつけがましい | 〇〇できる。 |
| 誰でも簡単に | 安っぽい | あなたらしく |
| 失敗しない | ネガティブ | 自信を持てる |
| AIが判定 | 冷たい | AIが寄り添う |

## チェックリスト

文案完成后，逐项检查：

### 内容

- [ ] 没有提到技术/AI性能
- [ ] 没有罗列功能
- [ ] 没有和竞品比较
- [ ] 有情感共鸣点
- [ ] 用户能想象自己变成谁

### 语气

- [ ] 親しみやすい敬語
- [ ] 押しつけがましくない
- [ ] ポジティブな表現
- [ ] 背中を押す感じ

### 結構

- [ ] 主标语（身份/价值观）
- [ ] 副标语（具体利益）
- [ ] CTA（行动号召）
- [ ] 前后呼应
