## 乔布斯营销哲学（1997）

### 原话摘录

| 英文 | 中文意译 |
|------|---------|
| "Marketing is about values." | 营销讲的是价值观 |
| "Not to talk about speeds and feeds, MIPS and megahertz." | 不要讲性能参数 |
| "Who is Apple? What do we stand for?" | 我们是谁？代表什么？ |
| "People with passion can change the world for the better." | 有热情的人能改变世界 |

### Nike 案例

Nike 卖的是"commodity"（日用品：鞋），但广告里：
- ❌ 不讲气垫技术
- ❌ 不讲比竞品更好
- ✅ 只做一件事：**Honor great athletes**（致敬伟大运动员）

**结果**：Nike 成为运动精神的代名词。

## 营销金字塔

```
        ▲ 身份需求（我想成为谁）
       ／ ＼    ← 营销要打这里
      ／   ＼
     ／情感需求＼（我想感受什么）
    ／─────────＼
   ／  功能需求  ＼（我需要什么功能）
  ／───────────────＼
 ／    表层需求      ＼（我说我想要什么）
─────────────────────────
```

| 层次 | 用户说的 | 用户真正要的 | 营销应该说的 |
|------|---------|-------------|-------------|
| 表层 | "推荐穿搭" | - | - |
| 功能 | "AI搭配" | 省时间 | - |
| 情感 | - | 减少焦虑、增加自信 | ✅ 打这里 |
| 身份 | - | 成为"穿出自己"的人 | ✅ 重点打这里 |

## 文案黄金法则

### 禁区（绝对不讲）

| 类型 | 错误示例 | 问题 |
|------|---------|------|
| 性能参数 | "AI准确率99%" | 用户不关心 |
| 技术规格 | "基于GPT-4" | 用户不懂 |
| 功能罗列 | "支持10种风格" | 没有情感 |
| 竞品比较 | "比XX更智能" | 拉低格调 |

### 核心（要讲什么）

| 类型 | 正确示例 | 打中的需求 |
|------|---------|-----------|
| 成为什么 | "穿出自己" | 身份 |
| 得到什么 | "不再迷茫的早晨" | 情感 |
| 我们相信 | "每个人都值得自信" | 价值观 |
| 情感共鸣 | "那种'就是这件'的感觉" | 情感 |

## 快速检验清单

写完文案后，问自己：

- [ ] 这句话有没有提到"AI"或技术术语？→ 有就删
- [ ] 这句话有没有提到功能参数？→ 有就改
- [ ] 这句话能让用户想象自己变成谁吗？→ 不能就重写
- [ ] 这句话能引发情感共鸣吗？→ 不能就重写
- [ ] Nike 会这样说吗？→ 不会就重写
