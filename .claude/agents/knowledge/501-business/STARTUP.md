# Business Analyst 启动必读

> 每次被调用时，先读这个文件理解核心概念

---

## 核心职责

| 领域 | 关键问题 | 输出 |
|------|---------|------|
| 目标客户 | 谁是我们的用户？ | 用户画像、市场细分 |
| 留存分析 | 用户为什么离开？ | 流失原因、留存策略 |
| 转化漏斗 | 如何提高付费？ | 漏斗优化、A/B测试 |
| 埋点规划 | 追踪什么指标？ | 事件清单、看板设计 |

---

## 用户意图分类

| 类型 | 说明 | 转化价值 |
|------|------|---------|
| 信息型 | 了解产品 | 低 |
| 比较型 | 对比竞品 | 中 |
| 交易型 | 准备购买 | 高 |
| 留存型 | 持续使用 | 最高 |

---

## 用户生命周期

```
Day 0: 注册
Day 1: 首次使用 ← 关键！
Day 3: 二次访问（习惯形成）
Day 7: 周活跃用户（W1留存）
Day 30: 月活跃用户（M1留存）
Day 90: 核心用户（长期价值）
```

---

## 转化漏斗基准

```
访问 → 注册 → 激活 → 试用 → 付费 → 续费
100%   30%    20%    10%    3%     2%
```

---

## SaaS 关键指标

| 指标 | 优秀 | 良好 | 需改进 |
|------|------|------|--------|
| 注册转化率 | >5% | 2-5% | <2% |
| Day 1 留存 | >40% | 25-40% | <25% |
| Day 7 留存 | >20% | 10-20% | <10% |
| 试用→付费 | >15% | 5-15% | <5% |
| 月流失率 | <3% | 3-7% | >7% |

---

## 埋点事件命名规范

```typescript
// 格式：动词_名词 (snake_case)
track('page_view', { page: '/pricing' });
track('button_click', { button: 'start_trial' });
track('signup_complete', { method: 'google' });
track('payment_complete', { plan: 'pro', amount: 980 });
```
