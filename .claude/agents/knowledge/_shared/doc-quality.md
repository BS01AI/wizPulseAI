# 文档质量规范：去除AI废话

> 输出文档前必须自检，删除低价值内容，保留重要信息

---

## 必须删除的内容

### 1. 重复说明

```markdown
❌ 同一个观点反复讲
"配置文件很重要。配置是系统的核心。正确的配置决定了系统能否正常运行。"

✅ 说一次就够
"配置文件决定系统行为。"
```

### 2. 模板化开头/结尾

```markdown
❌ AI废话
"在当今快速变化的技术世界中..."
"感谢您阅读本文..."
"不言而喻的是..."
"众所周知..."

✅ 直接开始
[直接进入正题]
```

### 3. 元说明

```markdown
❌ 关于文档本身的说明
"在这篇文章中，我们将探讨..."
"本段将介绍..."
"作为一个AI，我需要说明..."

✅ 直接写内容
[内容本身]
```

### 4. 冗长绕口的句子

```markdown
❌ 绕
"为了能够更好地理解这个概念的本质含义，我们需要首先从它的基本定义开始进行分析和探讨。"

✅ 简洁
"先看定义。"
```

### 5. 不必要的示例和补充

```markdown
❌ 为了凑字数的示例
"比如说，如果你想做A，你可以这样做...（500字示例）
又比如说，如果你想做B...（又500字）"

✅ 只保留关键示例
"示例：[最能说明问题的一个]"
```

---

## 自检清单

输出文档前，逐项确认：

- [ ] 是否有重复观点？合并或删除
- [ ] 开头是否有模板化废话？直接删除
- [ ] 是否有"本文/本段"等元说明？删除
- [ ] 长句能否压缩？不改变原意的情况下缩短
- [ ] 示例是否真的有助于理解？只保留必要的
- [ ] 是否有凭空新增的内容？只保留原始意图

---

## 保留的内容

- ✅ 技术准确性
- ✅ 重要论点
- ✅ 数据和事实
- ✅ 原始意图
- ✅ 必要的结构

---

## 输出格式

修改文档后，用1-3句话总结：

```
删除了X处重复说明、Y处模板化开头。
压缩了Z处冗长句子。
保留了核心技术内容和数据。
```
