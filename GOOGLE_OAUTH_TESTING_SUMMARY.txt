登录流程详解 - LOGIN FLOW DETAILS
====================================================================

步骤1：用户访问 Dashboard (localhost:3012)
       ↓
步骤2：点击 "Log In / Sign Up" 按钮
       ↓
步骤3：跳转到 Auth 站点 (localhost:3011/auth)
       ↓
步骤4：页面加载，显示 Google 登录按钮
       ↓
步骤5：用户点击 Google 按钮
       ↓
步骤6：调用 handleGoogleAuth()
       ↓
步骤7：supabase.auth.signInWithOAuth() 请求
       ↓
步骤8：获取 Google OAuth URL
       ↓
步骤9：window.location.href 跳转到 Google 授权页
       ↓
步骤10：用户在 Google 登录并授权
        ↓
步骤11：回调到 /api/auth/callback
        ↓
步骤12：验证授权码，创建用户 Session
        ↓
步骤13：设置 Cookie (domain: .localhost)
        ↓
步骤14：跳转回 Dashboard (localhost:3012/dashboard)
        ↓
步骤15：显示用户信息和订阅信息

====================================================================
故障排查 - TROUBLESHOOTING
====================================================================

问题1：Google 按钮不显示
原因：可能的原因
  1. Component 未加载（CSS 问题）
  2. JavaScript 执行错误
  3. 组件属性未传递
解决：
  - 打开 F12 看是否有 JS 错误
  - 检查 Network 标签中的请求状态
  - 使用隐身模式清除缓存

问题2：点击按钮无反应
原因：可能的原因
  1. onClick 处理器未绑定
  2. OAuth 配置缺失
  3. 网络连接问题
解决：
  - 查看 Console 是否有错误日志
  - 检查 Supabase 配置
  - 验证网络连接

问题3：Google 授权后卡住
原因：可能的原因
  1. Redirect URL 配置错误
  2. /api/auth/callback 路由缺失
  3. Cookie 设置失败
解决：
  - 检查 Supabase OAuth 配置
  - 验证回调路由存在
  - 查看浏览器 Application tab 中的 Cookie

问题4：跳转到 Dashboard 后显示"登录"
原因：可能的原因
  1. Cookie 域设置错误
  2. Session 未创建
  3. Dashboard 认证检查失败
解决：
  - 确认 Cookie domain = .localhost
  - 检查 Supabase Session 状态
  - 查看 Dashboard 认证逻辑
