## 4. 转化漏斗 (Conversion Funnel)

### 4.1 漏斗模型

```
                ┌──────────────────────────────────────┐
    Level 1     │          首页访问                    │  100%
                │   (www.wizpulseai.com)               │
                └───────────────┬──────────────────────┘
                                │ 目标: 60% 进入下一层
                ┌───────────────▼──────────────────────┐
    Level 2     │     产品线页面 (Life/Biz)            │  60%
                │   了解产品定位                        │
                └───────────────┬──────────────────────┘
                                │ 目标: 40% 进入产品页
                ┌───────────────▼──────────────────────┐
    Level 3     │       具体产品页                     │  24%
                │   (Fashion Advisor等)                │
                └───────────────┬──────────────────────┘
                                │ 目标: 50% 点击试用
                ┌───────────────▼──────────────────────┐
    Level 4     │         注册/登录                    │  12%
                │   (auth.wizpulseai.com)              │
                └───────────────┬──────────────────────┘
                                │ 目标: 80% 完成注册
                ┌───────────────▼──────────────────────┐
    Level 5     │          试用产品                    │  10%
                │   (实际使用功能)                     │
                └───────────────┬──────────────────────┘
                                │ 目标: 10% 付费转化
                ┌───────────────▼──────────────────────┐
    Level 6     │          付费订阅                    │  1%
                │   (Stripe Checkout)                  │
                └──────────────────────────────────────┘
```

### 4.2 关键转化点优化

| 转化点 | 当前问题 | 优化策略 | 预期提升 |
|--------|----------|----------|----------|
| 首页→产品线 | 无WizLife/WizBiz入口 | 添加产品生态区域 | +20% |
| 产品线→产品 | 卡片不够吸引 | 添加演示GIF/视频 | +15% |
| 产品→注册 | CTA不够突出 | 优化按钮设计 | +10% |
| 注册→试用 | 流程不够顺畅 | 简化onboarding | +10% |
| 试用→付费 | 价值感知不足 | 添加对比表 | +5% |

### 6.3 跨站点导航

#### 当前问题
```
Fashion站点 ──✕──> 无法返回 Life 页面
Life页面 ──✕──> 无面包屑返回首页
```

#### 解决方案

**方案A: 统一顶栏**
```
所有产品站点使用统一的迷你导航栏:
┌──────────────────────────────────────────────────┐
│ ← WizLife  |  Fashion Advisor  |  🌐 日本語 ▼   │
└──────────────────────────────────────────────────┘
```

**方案B: 品牌归属标识**
```
在产品站点Footer显示:
┌──────────────────────────────────────────────────┐
│  Fashion Advisor is part of WizLife by WizPulseAI │
│  [返回WizLife] [访问主站] [其他产品]              │
└──────────────────────────────────────────────────┘
```
